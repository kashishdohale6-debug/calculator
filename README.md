**Aesthetic Flask Calculator** is a modern and responsive web-based calculator developed using Python Flask, HTML, CSS, and JavaScript. The application features a clean and attractive user interface with a stylish gradient background and glassmorphism-inspired design. It supports basic arithmetic operations such as addition, subtraction, multiplication, and division, providing instant and accurate results. The project is designed to be user-friendly, mobile-responsive, and visually appealing, making it a great example of combining backend development with Flask and frontend design techniques to create an interactive web application.
